# mpv-chameleon v0.1.0 — draft

Your video adapts to your display.

Prepared notes for a future first release of automatic, display-aware HDR/SDR
output in mpv on macOS. No release or release tag has been published.
Licensed under GNU GPL version 3 or later (`GPL-3.0-or-later`).

- Separates source-format detection from display EDR capability.
- Keeps SDR films in SDR on either display; HDR10 uses PQ only on capable displays.
- Converts HDR10 to sRGB on SDR displays and restores original HDR settings on return.
- Uses a native, locally compiled Swift helper and validates unique display identity.
- Handles stale queries, timeouts, capability refresh, source changes and conservative fallbacks.
- Includes a transactional installer, legacy auto-hdr.lua migration, safe uninstall and backups.
- Includes independent unit tests, physical-display test harness, CI and technical documentation.

Validated locally on an Apple M1 Max MacBook Pro with its Liquid Retina XDR display
and an ASUS VS247 SDR monitor, macOS 15.7.9, mpv 0.41.0, libplacebo 7.360.1 and
FFmpeg 9.0.2, using gpu-next/vulkan/macvk. See the final
[verification report](../verification.md) for the exact tests and performance observations.

Limitations: no calibrated accuracy claim; no universal compatibility guarantee;
Intel/other macOS versions and displays unverified; HLG is converted to SDR;
no HDR10+/Dolby Vision support claim; wide-gamut SDR is limited to sRGB; native
Space fullscreen, manual drag responsiveness, unplug/replug and sleep/wake require
additional observational testing. ICC/profile conflicts are deliberately rejected.
The final local run observed three transition-related renderer drops and one
audio underrun; a focused follow-up showed no sustained issue. No flash-free or
zero-drop guarantee is made.

Install from the source archive with `./install.sh`; existing prototype users
use `./install.sh --migrate-legacy` after reviewing its backup/rollback behavior.
No precompiled helper, private test media, third-party shader or telemetry is included.
