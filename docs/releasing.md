# Preparing a release

The project is licensed under GPL-3.0-or-later. The owner approved the public
repository on 2026-10-10 and explicitly deferred a tagged release. The steps
below apply only when a release is subsequently requested. Local playback results are
recorded separately from untested claims in [verification](verification.md).

Before publication:

- Run `./tools/check.sh` and inspect its complete result.
- Complete the physical source/display gates in [testing](testing.md) when output
  behavior changes. License notices and prose changes do not change rendering.
- Inspect `git diff --check`, tracked files, license notices and sanitized results.
- Confirm the authenticated GitHub account and inspect any existing repository.
  Never overwrite unrelated content or force-push a published branch.
- Ensure the full GPLv3 license text is included and project notices specify
  `GPL-3.0-or-later`; do not add resale restrictions.

Repository: [jakeberv/mpv-chameleon](https://github.com/jakeberv/mpv-chameleon).
Keep Issues and [Actions](https://github.com/jakeberv/mpv-chameleon/actions/workflows/ci.yml) enabled. Repository description: “Automatic, display-aware
HDR/SDR switching for mpv on macOS.” Topics: mpv, macos, hdr, sdr, lua, swift,
apple-silicon, video, moltenvk.

Push the reviewed history and require successful Ubuntu and macOS Actions for
the exact source commit before annotating the release tag. For v0.1.0, create
`mpv-chameleon-v0.1.0.tar.gz` with
`git archive --prefix=mpv-chameleon-v0.1.0/ v0.1.0`, then generate and verify its
SHA-256 digest. The archive must contain LICENSE and the matching source,
installation scripts, tests and build instructions.

Publish [release notes](releases/v0.1.0.md) with usable links from GitHub's release
page. Upload only the source archive and checksum. Do not distribute build
directories, binaries, private logs, research downloads or media. GitHub's
autogenerated source archives are also suitable. Build native helpers locally
during installation.

If Actions fail, fix and verify before publishing the release. Hosted CI does
not establish physical HDR behavior; keep that evidence and its limits explicit.
